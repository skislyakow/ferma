## 2. Фаза A — CPA/партнёрские программы (работает с 0 подписчиков)

CPA не требует аудитории: платят за действие (регистрация, покупка, установка), а не за показы.
Пост с ссылкой увидят даже 15 подписчиков — если хоть один совершит действие, это деньги.
Это единственный рабочий источник сейчас.

### Как это работает в нашей ферме
Мы уже умеем: `_inject_cpa` в Telegram Publisher. Для VK нужно то же самое —
CPA-ссылка дописывается в конец поста перед `vk.post_to_wall()`.

### Подходящие партнёрки под наши ниши

| Ниша | Группа | CPA-сети | Офферы |
|------|--------|----------|--------|
| Наука и научпоп | Популярная Наука | Admitad, CityAds, Mylead | Онлайн-курсы (Skillbox, GeekBrains), VPN, книги |
| Развлечения | Интересное! | Admitad, CityAds | Онлайн-кинотеатры (Kion, Ivi, Okko), игры |
| Путешествия | Симфония леса | Admitad, Mylead | Гостиницы (Ostrovok), билеты (Aeroflot Bonus), туры |
| Урбанистика | Урбанистика | Admitad, Mylead | Товары для дома, мебель, ремонт, WB/Ozon |
| СМИ/фото | RE:POST | Admitad | Финансовые новости → крипто-биржи (уже есть BingX), VPN |

**Важно**: у нас уже работает BingX для crypto (Telegram). Его же можно повесить на RE:POST —
финансовые новости идеально конвертят в крипто-регалки.

### Шаги для запуска CPA на VK
1. Регистрация в CPA-сети (Admitad/CityAds) — под наш аккаунт VK (не на доноров)
2. Подобрать офферы под ниши (модерация сети должна одобрить тематику группы)
3. Ссылки вставить в `.env` каждого VK-канала:
   ```
   CPA_LINKS=https://...off1,https://...off2
   CPA_INSERT_EVERY=5
   ```
4. Код: добавить `_inject_cpa()` в `core/vk_common.py` (один хелпер для всех 4 скриптов
   интересно/урбанистика/наука/лес) — в `process_entry()` перед `vk.post_to_wall()`
5. Деплой на VPS + перезапуск screen-ов
6. Показатель успеха: **CPC/CPA конверсия**. С 15 подписчиков CTR будет 0.5–2%,
   т.е. 1 клик на 50–200 показов. Реальный доход начнётся при 1000+ просмотров/пост.

### Ограничение честности
Не вставлять CPA в КАЖДЫЙ пост — VK банит за спам. Интервал `CPA_INSERT_EVERY=5–10`.
Ссылки — через сократитель (vkrf.ru, vk.link) для снижения антиспам-фильтров.

## 3. Фаза B — VK-монетизация по мере роста подписчиков

Требования ниже — устоявшиеся правила VK, но точные цифры порогов могут меняться.
**Проверить перед подключением** в разделе «Монетизация» настроек сообщества.

### 3.1 VK Donut (платная подписка на контент)
- **Порог**: 1000+ подписчиков, открытый паблик
- **Как**: подписчики платят ежемесячно за эксклюзив → доход зависит от % подписчиков
- **Нашим группам**: сначала сменить тип «группа» → «паблик», набрать 1000 подписчиков.
  Логичнее всего на **Симфония леса** (обои/медитации за подписку) и **Популярная Наука** (разборы/глубокие посты)
- **Реалистично**: 1000 подписчиков × 5% конверсия в Donut × 150₽/мес = 7500₽/мес с одной группы

### 3.2 Монетизация рекламы в постах (VK Реклама)
- **Порог**: 5000+ подписчиков, открытый паблик, администратор 18+
- **Как**: VK вставляет рекламу в N-й пост, автор получает % от дохода VK
- **Реалистично**: 5000 подписчиков × 5% ER × 100₽ CPM ≈ 10–30к₽/мес
- **Нашим группам**: далеко, но это главный аргумент ЗА смену «группа»→«паблик» сейчас,
  пока аудитория маленькая (переезд дорогого стоит)

### 3.3 VK Маркет (продажа товаров в группе)
- **Порог**: любой открытый паблик, но продажи требуют трафика
- **Нашим группам**: неактуально до 1000 подписчиков. Единственный кейс —
  Симфония леса продажа цифровых обоев/AR-масок через маркет
- **Сейчас**: пропустить

### 3.4 Прямые рекламодатели / биржи рекламы
- **Порог**: 5000–10000 подписчиков (Plibber, Weitive, Wildjam)
- **Нашим группам**: неактуально сейчас

## 4. Фаза C — VK как трафик-канал в Telegram (главный вектор)

**Ключевой инсайт**: наши деньги в Telegram (CPA там работает, аудитория доноров огромная).
VK — это бесплатный источник аудитории, который VK сам тащит в рекомендации.
Каждая группа VK должна приводить подписчиков в Telegram-канал, где они увидят CPA.

### Как это делаем (частично уже в коде)
- В каждом VK-посте подпись:
  ```
  Больше такого — в нашем Telegram: t.me/{channel}
  ```
- RE:POST уже так делает (`_crosspost_to_vk`, подпись с `t.me/...`). Проверить,
  что в остальных 4 VK-скриптах подпись есть (по коду — нет, только в repost!)

### Задача на 1 шаг
- Добавить подпись `\n\nБольше такого в Telegram: t.me/...` в `process_entry()` → `format_post`
  для интересно/урбанистика/наука/лес (сейчас format_post = только эмодзи + заголовок)
- TARGET_CHANNEL для каждой VK-группы = соответствующий Telegram-канал

## 5. Критические действия прямо сейчас (по приоритету)

1. **[CPA] Подключить партнёрки к VK-каналам** — единственный источник с 0 подписчиков.
   Реализация: хелпер `_inject_cpa()` в vk_common + `.env` конфиги + деплой.
2. **[Трафик] Добавить ссылку на Telegram в каждый VK-пост** (кроме уже настроенного repost) —
   превращаем VK в воронку. 5 минут кода.
3. **[Тип] Сменить «группа» → «паблик» на всех 5** — даёт доступ к VK Рекламе и Donut
   на будущее. Дешевле сделать сейчас, пока подписчиков мало.
4. **[Рост] Выбор «лидера» для набора аудитории**: Симфония леса или Популярная Наука —
   ниши, где VK сам раздаёт охват в рекомендациях. Цель: 1000 подписчиков → включить Donut.
5. **[Контент] Рост просмотров**: видео-посты в VK получают больший охват, чем фото.
   У нас видео уже постится (интересно/наука/лес) — увеличить долю видео в urbanistika.

## 6. Дорожная карта (что и когда)

| Этап | Условие | Действие | Ожидаемый доход |
|------|---------|----------|-----------------|
| Сейчас | 0 подписчиков | CPA-ссылки в посты + подпись на Telegram | 0–5к₽/мес (случайные конверсии) |
| 100 подписчиков | рост | Начать постить видео чаще, анализ CTR | рост кликов CPA |
| 1000 подписчиков | рост | Сменить на паблик + подключить Donut | +5–10к₽/мес |
| 5000 подписчиков | рост | Подключить VK Рекламу в постах | +10–30к₽/мес |
| Параллельно | всегда | VK → Telegram воронка | CPA в Telegram окупает всё |

**Главный принцип**: VK-группы не продают рекламу напрямую (для этого слишком малы) —
они приводят людей в Telegram, где CPA работает на полную. VK монетизацию подключаем
только как бонус по мере роста.
